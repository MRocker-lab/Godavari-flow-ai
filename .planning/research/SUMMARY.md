# Research Summary — GODAVARI FLOW AI

## Recommended Stack Summary
- **Runtime & Bundler:** Vite + React + TypeScript (`npm run dev` single-command startup)
- **Routing:** React Router v6/v7 (`/` Pilgrim Portal, `/command` Authority Command Centre)
- **Styling & Design System:** Tailwind CSS + Scoped CSS Variables (`pilgrim` & `command` themes) + Radix UI primitives + `lucide-react` icons
- **Maps:** Leaflet + React-Leaflet with CartoDB Positron (Light) & Dark Matter (Dark) tiles + offline SVG fallback
- **Charts:** Recharts + custom SVG operational gauges
- **State & Sync:** Zustand + `localStorage` persistence + `BroadcastChannel` real-time cross-tab sync + Service/Repository Adapter interfaces
- **Localization & Accessibility:** Complete EN / TE / HI dictionary system + Senior Citizen Mode + WCAG AA contrast & reduced-motion support
